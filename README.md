# Japanese Game Filename Fixer (Java)

Утилита для исправления повреждённой кодировки имён файлов в японских играх.
При распаковке архивов могут быть сбои кодировок с заменой их на CP1251 или CP866. В итоге игра не может найти свои ресурсы и выдаёт ошибку.

## Возможности программного инструмента
- Выбор папки с игрой через визуальный интерфейс.
- Рекурсивное сканирование всех вложенных подпапок.
- Выбор исходной и целевой кодировки (по умолчанию: `windows-1251` -> `Shift_JIS`).
- Режим **"Сухой прогон"** для безопасной проверки названий перед переименованием.
- Режим автоматической замены запрещённых символов Windows (`|`, `?`, `*` и т.д.) на `_`.
- Подробный лог операций.

### Внимание!
 - Если программа предлагает заменить запрещённые символы - это скорее всего ошибка в изначальной кодировке. Попробуйте сменить на другую - эта функция служит в первую очередь для обнаружения проблем
 - Данная программа предлагает лишь исправления кодировок в названиях файлов. Для запуска самой игры после переименования используйте Locale Emulator
